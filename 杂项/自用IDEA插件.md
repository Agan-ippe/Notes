# 实用工具

- [Chinese (Simplified) Language Pack / 中文语言包](https://plugins.jetbrains.com/plugin/13710-chinese-simplified-language-pack----)

- [CodeGlance Pro](https://plugins.jetbrains.com/plugin/18824-codeglance-pro) 代码右侧小地图

- [Generate All Getter And Setter](https://plugins.jetbrains.com/plugin/18969-generate-all-getter-and-setter) 快速获取 all getter/setter

- [GsonFormatPlus](https://plugins.jetbrains.com/plugin/14949-gsonformatplus) JSON 对象转实体类
- [Plugin Logo Key Promoter X](https://plugins.jetbrains.com/plugin/9792-key-promoter-x) 快捷键提示
- [MyBatisX](https://plugins.jetbrains.com/plugin/10119-mybatisx) 这个真神没意见吧
- String Manipulation 字符串处理 快捷键：shift+m
- [Translation](https://plugins.jetbrains.com/plugin/8579-translation) 翻译插件
